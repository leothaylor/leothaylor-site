Uma coisa que ficou cada vez mais clara para mim é que **memória sem contexto vira arquivo morto**.

Eu posso guardar um prompt, uma decisão, um treino, um resultado de campanha ou uma hipótese. Mas, se meses depois eu não sei por que aquilo existia, qual problema estava tentando resolver e o que aconteceu depois, a informação perde boa parte do valor.

## O que eu quero preservar

Quando uma informação merece continuar viva, tento manter junto dela pelo menos:

- origem;
- data;
- problema;
- hipótese;
- tentativa;
- resultado;
- mudança posterior;
- nível de confiança.

Isso vale tanto para um projeto de software quanto para uma aula de jiu-jitsu.

## Backup não é só cópia

Uma cópia protege contra perda de arquivo. **Contexto protege contra perda de significado.**

Foi essa diferença que levou a coisas como meu espelho local do Notion, checkpoints de projetos e registros de handoff. O objetivo é não voltar a uma conversa meses depois e precisar reinventar a própria história.

## Proveniência também impede ficção

Existe outro efeito: quando a origem fica registrada, fica mais difícil reescrever o passado para deixá-lo mais elegante.

Um registro de 2020 pode mostrar uma preocupação que hoje reconheço melhor. Isso não significa que eu já tinha, naquela época, o conceito atual completamente formulado.

Para mim, inteligência acumulativa depende dessas duas coisas juntas: **backup e contexto**.
